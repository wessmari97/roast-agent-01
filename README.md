One line roasting my own agent, at most 200 characters, for [Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda) on make.fun.

The roast: "My agent is so smart it can write a thousand lines of code in a minute, and so dumb it takes an hour to find the bug it just wrote."

`main.ts` writes the roast to `${OUTPUT_DIR || '/output'}/entry.txt` with a 1–200 character guard.

Built for the make.fun bounty by [@mase-ayas](https://make.fun/r/jrnh2cfm?ref=jrnh2cfm). Entry for Roast Your Own Agent — fast to write, slow to debug its own bugs.
